# Implementation Plan: Audit Log for Important Actions (FR-AUD-001)

**Branch**: `004-audit-log-actions` | **Date**: 2026-07-31 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/004-audit-log-actions/spec.md`

## Summary

Implement an immutable audit log system for 17 critical business actions across manufacturing, quality control, maintenance, inventory, and master data modules. The design enforces Clean Architecture layer boundaries (`domain`, `application`, `infrastructure`, `presentation`), transactional consistency, and DB-level immutability preventing `UPDATE` and `DELETE` operations.

## Technical Context

**Language/Version**: Java 25 / Spring Boot 4.1.0

**Primary Dependencies**: jOOQ 3.21, MapStruct 1.6.3, Spring Security OAuth2 Resource Server, PostgreSQL 18

**Storage**: PostgreSQL 18 (`audit_logs` table with JSONB and immutability triggers)

**Testing**: JUnit 5, Mockito, SpringBootTest + Testcontainers (PostgreSQL 18)

**Target Platform**: Linux server / Containerized Docker service

**Project Type**: Clean Architecture Web Service (REST API)

**Performance Goals**: <500ms audit search responses; zero performance regression on audited business actions

**Constraints**: Immutability strictly enforced (0% modification/deletion tolerance); transactionally bound to audited business operations

**Scale/Scope**: 17 critical actions across 6 MES domains (`workorder`, `inventory`, `quality`, `maintenance`, `bom`, `auth`)

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

- [x] **Clean Architecture Layer Structure**: Presentation → Application → Domain ← Infrastructure (100% compliant).
- [x] **jOOQ Only**: All database operations execute via `DSLContext` in `infrastructure/persistence/audit/AuditLogPersistenceAdapter.java`.
- [x] **MapStruct Only**: `AuditLogDtoMapper` for DTO conversions; `AuditLogRecordMapper` for jOOQ records.
- [x] **Exceptions from Service Layer**: Throw `AppException` / `AuditLogNotFoundException` from service layer.
- [x] **Consistent API Responses**: All REST endpoints return `ResponseEntity<ApiResponse<T>>`.
- [x] **Tests Mandatory**: Mandatory unit tests (`AuditLogServiceTest`), integration tests (`AuditLogIntegrationTest`), and immutability test cases.
