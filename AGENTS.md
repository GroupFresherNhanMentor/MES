## Key Conventions

- All unimplemented stubs throw `UnsupportedOperationException("Not implemented")`
- Database schema is generated via jOOQ codegen into `fpt.qn.mes.jooq`
- Flyway migrations: `be/src/main/resources/db/migration/`
- Run backend: `cd be && ./mvnw spring-boot:run`
- Docker services: `docker-compose up -d` (PostgreSQL)

## Architecture Summary

```
presentation → application.port.in → (domain) ← application.service
                                                        ↓
                                              domain.repository (interface)
                                                        ↑
                                          infrastructure.persistence (jOOQ impl)
```

Every new module must have: `domain/entities/`, `domain/repository/`, `application/port/in/`,
`application/service/`, `application/dto/`, `application/mapper/`, `application/exception/`,
`infrastructure/persistence/`, `presentation/`.
